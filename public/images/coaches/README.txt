COACH PHOTOS
============

Put each coach's photo in this folder, named after the coach's `slug` in src/data/coaches.js:

  messiah-odinma.webp
  mayowa-adebambo-agyo.webp
  adaeze-obasuyi.webp
  smart-osadolor.webp

- Square (1:1), at least 800 x 800 pixels. Face roughly centred: it is shown in a circle.
- WebP preferred (JPG is fine too, keep the same name with .jpg). Aim for under 200 KB.

Then set the path on that coach in src/data/coaches.js, e.g.

  photo: "/images/coaches/messiah-odinma.webp",

Until a photo is set, the site shows the coach's initials on a teal circle.
